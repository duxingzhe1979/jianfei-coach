# 特殊场景应对

> 来源：《AI减重教练 Skill｜从记录到复盘的完整操作手册》第六节。用户遇到饭局、外食、假期等场景时加载本文件。

## 饭局和喝酒

**喝酒前**：先补蛋白质，出门前喝蛋白粉或吃两袋鸡胸肉。空腹喝酒吸收快、醉得快、自控力崩得快。

**选酒**：白酒控量，红酒略优，啤酒最差（碳水加酒精双杀）。

**配菜三选三不选**

| 选 | 不选 |
|----|------|
| 凉拌菜、拍黄瓜 | 花生米（脂肪 45g/100g） |
| 清蒸鱼、白灼虾 | 红烧肉、回锅肉 |
| 酱牛肉（控量） | 火腿肠、午餐肉 |
| 豆腐豆干 | 油炸食品 |

**喝汤一律不喝。别喝含糖饮料。酒局结束直接回家，不吃夜宵。**

**第二天早上不称体重**，称了也是水分。后天才准。

## 外食点菜

**通用结构**：一份蛋白质 + 一份蔬菜 + 适量粗粮主食。

**替代思路**：番茄鸡蛋盖饭 → 番茄鸡蛋盖芋头；拉面 → 要牛肉不要面；炒菜 → 要求少油。

**核心原则**：不否定想吃的菜，只换它的载体。番茄炒蛋没问题，问题在盖在白米饭上。

## 烧烤

| 能吃（控量） | 不能吃 |
|-------------|--------|
| 羊肉串挑瘦的吃，5 到 8 串 | 烤面筋（精制碳水） |
| 烤鱼吃鱼背肉，不吃焦皮 | 烤肠、火腿肠 |
| 烤鸡翅 | 烤土豆大量吃 |
| 烤韭菜、烤金针菇 | 烤馒头片 |

## 假期和反弹

反弹 2 到 4 公斤，绝大部分是钠水和糖原，不是脂肪。

**判断标准**：看回落速度。2 到 3 天回到原位，是水。一周还回不去，才是真长了。

**最重要的一点**：反弹不可怕，反弹后放弃才可怕。前五次失败的核心模式不是反弹本身，是"反弹 → 觉得自己失败 → 情绪崩 → 放开吃 → 真失败"。
